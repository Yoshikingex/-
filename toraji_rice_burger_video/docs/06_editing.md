# 06 編集・仕上げ（本編＋ショート）

## 結論

- 編集ソフトは **CapCut（パソコン版）** を推奨。理由：テロップ・自動字幕・BGMの音量自動調整・背景削除が標準で入っていて、専門知識なしで仕上げられる（Premiere Pro でも同じ手順で可）
- 設計図は `output/animatic_720p.mp4`（仮編集）と `output/timings.json`（各シーンの開始時間と尺）。**仮映像を Higgsfield の本番クリップに1つずつ差し替えていく**

## 1. 素材フォルダの作り方

```text
toraji_rice_burger_video/
└─ edit/                         ← 新しく作る（Git管理外にしてよい）
   ├─ video/  S01.mp4 … S31.mp4   ← Higgsfieldで生成した動画（シーン番号で名前を付ける）
   ├─ voice/  S01.mp3 … S31.mp3   ← ElevenLabsのナレーション
   ├─ se/                         ← 効果音
   └─ bgm/                        ← BGM
```

## 2. タイムラインの構成

| トラック | 中身 |
|---|---|
| 映像1 | 本番クリップ（S01〜S31） |
| 映像2 | 主人公ワイプ（任意：S05材料・S17焼肉など長いカットの右下に H2 を小さく） |
| テキスト | テロップ（`docs/02_script_storyboard.md` のテロップ列）＋章ラベル |
| 音声1 | ナレーション |
| 音声2 | 効果音（02 の SE 列） |
| 音声3 | BGM |

## 3. 手順（1ステップずつ）

1. **仮編集を下敷きにする**：CapCutに `animatic_720p.mp4` を読み込み、映像1に置く（尺の目安）
2. **ナレーション差し替え**：`voice/S01.mp3`〜を、`timings.json` の `start` の位置に並べる → 仮編集の音声はミュート
3. **映像差し替え**：`video/S01.mp4`〜を同じ位置に上書き。ナレーションより映像が短いときは、同じシーンの別テイクをつなぐか、スピードを0.8倍に
4. **テロップ**：02 のテロップ列を入力（下のスタイル）
5. **効果音**：02 の SE 列の位置に置く
6. **BGM**：全体に敷き、ナレーション中は自動で下げる（CapCut「オーディオダッキング」等）
7. **色**：全クリップに同じ色補正（暖色寄り・彩度+10・コントラスト+5）。AI生成は色がバラつくので必須
8. **確認**：スマホで通しで見る（テロップが小さすぎないか・音量が揃っているか）
9. **書き出し**：下の設定

## 4. テロップのスタイル（仮編集と同じ見た目）

| 種類 | フォント | 色 | フチ | 位置 |
|---|---|---|---|---|
| メイン（1行目） | Noto Sans JP Black 54px | 白（POINTは黄 #FFD63C） | 黒 9px | 下部中央 |
| サブ（2行目） | Noto Sans JP Bold 40px | 白 | 黒 7px | メインの下 |
| 章ラベル | Noto Sans JP Black 30px | 白 | 赤帯 #D61620 | 左上 |
| タイトル（S04） | Dela Gothic One 90px前後 | 黄 | 濃赤 12px | 中央 |

- 下部は黒の半透明グラデ帯を敷くと、どんな映像でも読める
- フォントはどちらも無料（Google Fonts・商用可）【確定：SIL Open Font License】

## 5. 音

| 項目 | 目安 |
|---|---|
| BGM | 明るいアコースティック／ポップ。**YouTube オーディオライブラリ**（無料・収益化OK）から選ぶと権利トラブルなし |
| BGMの音量 | ナレーション中 −24dB前後、ナレーション無し −16dB前後 |
| 全体の音量 | −14 LUFS 前後（YouTubeの基準に合わせる）【推測：一般的な目安】 |
| 効果音 | 焼き音・炒め音は長め（2〜3秒）で“音のシズル”を作る。ポン・キラーンは短く |

## 6. 書き出し設定

- 解像度 1920×1080（素材が4Kなら3840×2160）／30fps／H.264／ビットレート 16Mbps 以上／音声 AAC 48kHz 320kbps
- ファイル名：`toraji_rice_burger_main_v1.mp4`
