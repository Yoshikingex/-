# 01 レシピ｜トラジライスバーガー・スペシャル（2個分）

- 調理時間：約25分（ごはんは炊いてある前提）
- 難易度：★★☆（フライパン1つ）
- 1個あたり材料費：約300〜400円【推測：2026年のスーパー価格の目安】

## 道具

- フライパン（26cm前後・フッ素加工）＋フタ
- セルクル（丸いステンレス型）直径10cm ×1　※無ければ、ライスバンズはラップで手成形・目玉焼きは型なしでOK
- ラップ／刷毛（スプーンの背でも可）／キッチンペーパー

## 材料

**ライスバンズ（4枚＝2個分）**
- 温かいごはん　400g（1枚100g）　※少し固めに炊いたものが崩れにくい
- 片栗粉　小さじ2
- 塩　少々
- ごま油　大さじ1（焼き用）
- 醤油　小さじ2（仕上げ用）

**甘辛焼肉**
- 牛こま切れ肉（または牛バラ切り落とし）　160g　→ 1〜2cm幅に刻む
- 玉ねぎ　1/2個（100g）　→ 5mm幅の薄切り
- 焼肉のタレ　大さじ3　※【未確定】トラジ自社のタレが市販されていればそれを使うと動画的に◎
- サラダ油　小さじ1
- 白ごま　少々（好みで）

**トラジ流オーロラソース**
- マヨネーズ　大さじ2
- ケチャップ　大さじ1
- 焼肉のタレ　小さじ1（隠し味）
- 黒こしょう　少々

**トッピング**
- 卵　2個
- トマト　1個 → 1cm厚の輪切り2枚
- レタス（グリーンリーフ）　2〜4枚
- 水　大さじ1（目玉焼き用）／サラダ油 少々
- ワックスペーパー 2枚（包む場合）

## 作り方

### 段取り（この順番だと全部温かいまま組み立てられる）

| 時間 | 作業 |
|---|---|
| 0〜3分 | ①ソースを混ぜる／②トマトを切る・レタスを洗って水気を拭く |
| 3〜15分 | ③ライスバンズを成形して焼く（焼いている間に玉ねぎ・牛肉を切る） |
| 15〜20分 | ④焼肉を炒める（バンズは皿に取り出しておく） |
| 20〜23分 | ⑤目玉焼き（最後に作る＝黄身がとろとろのまま） |
| 23〜25分 | ⑥組み立て・包む |

### ① 特製ソース
1. ボウルにマヨネーズ大さじ2・ケチャップ大さじ1・焼肉のタレ小さじ1・黒こしょう少々を入れて混ぜる。

### ② 野菜
1. トマトは**1cm厚**の輪切り（薄いと食感が負ける）。
2. レタスは冷水に2〜3分つけてシャキッとさせ、**キッチンペーパーで水気を完全に拭く**（水っぽさ＝ベチャつきの原因）。

### ③ ライスバンズ
1. 温かいごはんに片栗粉・塩を混ぜ、4等分する。
2. ラップで包み、セルクルに押し込むか手で**直径10cm・厚さ1.5cm**の円盤にする。ぎゅっと固めるのが崩れないコツ。
3. フライパンにごま油大さじ1を中火で熱し、バンズを並べる。**触らず片面4分**、焼き色がついたら返してもう片面4分。
4. 両面に醤油を刷毛で塗り、各面10〜20秒ずつ焼いて香ばしくする。皿に取り出す。

### ④ 甘辛焼肉
1. 同じフライパンにサラダ油を足し、玉ねぎを中火で2分炒める。
2. しんなりしたら牛肉を加え、色が変わるまで炒める。
3. 焼肉のタレ大さじ3を加え、**汁気がほぼなくなるまで**1〜2分からめる（汁が残るとバンズが崩れる）。取り出す。

### ⑤ 目玉焼き
1. フライパンをさっと拭き、サラダ油を薄くひく。内側に油を塗ったセルクルを置き、卵を割り入れる。
2. 弱火にして水大さじ1をセルクルの外側に入れ、フタをして**2分半**。黄身が半熟になったら型を外す。

### ⑥ 組み立て
下から **バンズ → 焼肉 → 目玉焼き → トマト → ソース → レタス → バンズ**。
ワックスペーパーで包むと持ちやすく、断面もきれいに見せられる。

## 失敗しやすいポイント

| 症状 | 原因 | 対策 |
|---|---|---|
| バンズが崩れる | 成形がゆるい／ごはんが冷めている | 温かいうちにラップで強く押す。片栗粉を忘れない |
| バンズが焦げる | 火が強い | 中火〜中弱火。焼き色は4分で確認 |
| 全体が水っぽい | レタスの水気・焼肉の汁 | レタスは拭く、焼肉は汁気を飛ばす |
| 黄身が固まる | 火を入れすぎ | 弱火・2分半。卵は最後に焼く |

## アレンジ（動画の概要欄・コメント返し用）

- チーズ：目玉焼きの上にスライスチーズ → 焼肉の熱でとろける
- 辛口：ソースにコチュジャン小さじ1/2
- キムチ：レタスの代わりに汁気を切ったキムチ

## 保存

- 作りたてがおすすめ。包んだものは**冷蔵で当日中**。卵が半熟なので持ち歩く場合は目玉焼きを固焼きにする。
