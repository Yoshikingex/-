# 銀座ラウンジ プランタン — スクロール連動ワンページサイト

Three.js（背景の珈琲豆・金粉パーティクル）と GSAP ScrollTrigger（ピン留め・横スクロール・動画のフルスクリーン展開）、Lenis（慣性スクロール）で構成した、ワンページ完結型のサイトです。

## 構成

```
index.html            ページ本体（全セクション）
css/style.css         スタイル
js/main.js            GSAP ScrollTrigger / Lenis の演出
js/scene.js           Three.js 背景シーン（豆のインスタンス描画・スクロール連動・商品セクションで渦を巻く）
assets/video/         生成動画 2 本（縦：ヒーロー、横：フィルムセクション）とポスター画像
assets/img/           動画から切り出した静止画（ストーリー・商品・挨拶）
```

## 動かし方

ビルド不要。`index.html` をブラウザで開くだけで動きます（Three.js / GSAP / Lenis / フォントは CDN 読み込みのため、インターネット接続が必要です）。

ローカルサーバーで確認する場合：

```
npx serve .
```

## セクション

1. Hero — 縦動画のアーチ型フレームがスクロールで全画面に拡大
2. Greeting — 行マスクと文字単位のスクラブ表示
3. Story — ピン留めした横スクロール（CHERRY / ROAST / DRIP / CUP）
4. Coffee — 商品ボックスの 3D チルト、背景の豆が商品の周りに集まる
5. Film — 横動画がスクロールで全画面展開、再生はビュー内のみ
6. Menu — おつまみ All ¥500 のカードをスタッガー表示
7. Info — 営業時間・住所・電話・アクセス

店舗情報は公式サイト（Wix）の掲載内容をもとにしています。
